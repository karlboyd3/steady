# Play Console — Content rating questionnaire (draft answers)

The content rating is generated by the IARC questionnaire. Steady is a
utility/health app (not a game). Expected outcome: **Everyone / PEGI 3 / rated
for all ages.**

## Category

- **App category:** Reference, News, or Educational  → choose **"Health & Fitness"**
  when prompted (Steady is a utility/health app, not a game).

## Questionnaire answers (all "No" unless noted)

| Topic | Answer |
|---|---|
| Violence (cartoon, fantasy, realistic) | No |
| Blood / gore | No |
| Sexual content or nudity | No |
| Profanity or crude humor | No |
| Controlled substances (alcohol, tobacco, drugs) | No |
| Gambling / simulated gambling | No |
| User-generated content / user interaction | No |
| Shares user's physical location | No |
| Allows purchase of digital goods | No |
| Data collection / sharing | No (see data-safety.md) |

### Notes / possible clarifications

- **In-app "coins":** These are a cosmetic reward earned only by completing
  sessions. They **cannot** be purchased, exchanged for money, or gambled — this
  is not simulated gambling and there are no in-app purchases.
- **Health content:** General fitness/exercise instructions only. No medical
  treatment, medication, or diagnostic content.
- **Contact/interaction:** No chat, no social features, no user-to-user contact.

## Target audience & content

- **Target age group:** 18+ primary, but appropriate for all adults; not
  designed for or directed at children.
- **Appeals to children?** No.
